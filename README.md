# Candy Cascade Craze

Prompt: Candy Crush-Style Match-3 Game

Create a beautiful, polished Candy Crush-style match-3 puzzle game with a fun, satisfying mobile game experience.

Gameplay

An 8×8 board filled with colorful candy pieces.

Players can drag or swipe to swap two adjacent candies.

Only valid swaps that create a match are allowed.

Match 3 or more identical candies to clear them.

Candies above fall smoothly into empty spaces, and new candies drop from the top.

Automatically support chain reactions (combos) when new matches are created.

Special Candies

Striped Candy: Clears an entire row or column.

Wrapped Candy: Explodes and clears nearby candies.

Color Bomb: Clears every candy of a selected color.

Allow exciting combinations between special candies.

Design

Bright, colorful, glossy candy theme.

Rounded, attractive candy pieces with soft shadows and highlights.

Clean, modern interface with a premium mobile game look.

The game board should be the main focus with minimal UI.

Animations

Smooth candy swapping.

Satisfying popping effects when candies match.

Falling candies with natural movement.

Particle effects, floating score numbers, and combo animations.

Subtle screen shake for powerful matches and special candy explosions.

User Interface

Display the current score.

Add a pause/restart button.

Keep the interface simple, clean, and uncluttered.

Overall Feel

The game should feel smooth, responsive, addictive, and highly polished, with the same satisfying game feel as a professional commercial match-3 mobile game. Focus entirely on the core gameplay experience and visual polish.
